# K17 公共底座开发记录

日期：2026-10-29。K17 进行中；K17.5 企微统一接入依用户决定暂停。

- `access.py` 和 `local_application.py`：本地凭据映射、任务创建、按任务资源授权、修订与确认的隔离入口；群资源输出需额外授权。没有连接真实员工目录或生产知识权限。
- `task_store.py`：隔离 SQLite 事务、任务/修订、版本绑定确认、请求幂等、确认事件 outbox 和租约。本地测试覆盖重启、并发、重放、授权撤销和旧确认。Outbox 为至少一次；接收端必须幂等，未连接外部消息渠道。
- `confirmation_graph.py`：LangGraph 确认中断/恢复，恢复时重查授权与修订；确认结果仍须领域事务提交。LangGraph 1.0.10 内存测试通过；以隔离探针环境 LangGraph 1.2.17 + SQLite saver 3.1.2 在两个独立进程完成中断与恢复。SQLite 探针不代表 PostgreSQL 或多 worker 验收。
- `knowledge_gateway.py`：项目/产品检索逐文档授权过滤、精确版本补读、全文和项目资产和产品原图按需读取、初步证据结构与追溯回调。合成 MCP 2.3 stdio 成功检索/补读/图像及错误测试通过；真实知识库成功链路、实际权限与资产尚未验证。
- `model_adapter.py`：明确模型、端点和凭据环境变量，调用限制、超时、工具调用、JSON 结果及错误分类。本机模拟 API HTTP 测试通过，未调用真实国产模型；进程内限次不等于持久化跨进程限制。
- `features.py`：模块版本、依赖检查和默认关闭；尚未在全部未来模块接入。

本机 Docker 服务未运行，未配置 PostgreSQL；尝试访问 Python 包索引时遇到 TLS EOF，未安装 PostgreSQL checkpoint 驱动。跨平台正式依赖锁文件、PostgreSQL checkpoint/业务库、正式 worker 部署、实际渠道、企业身份与生产知识授权均未完成。企业微信与 K16 继续暂停，未进行真实客户端及生产部署验收。

- 本轮聚合验证：31 项测试通过，包含上述本地入口、授权、图、事务、模拟 HTTP 与模拟 MCP；`tests.test_cloud_models` 既有回归包含在内。

- 后续增量：隔离 SQLite 持久任务队列和 worker 支持重启领取、租约过期恢复、最多三次尝试、执行前和保存前重查输入修订及任务所有人授权，结果、任务版本与 outbox 在同一事务提交。`tests.test_agent_worker`、`tests.test_agent_local_application`、`tests.test_agent_task_store` 共 13 项通过；未验证多进程生产数据库、真实模型副作用和外部消息投递。处理函数仅限无外部写入的本地操作。

- 本轮增量：确认图按确认单隔离并绑定确认人，通过领域事务提交；本地入口从对应修订生成确认内容。SQLite 模型任务队列与通用队列隔离，模型调用限次和结果分类持久保存，本机模拟 HTTP 验证调用和重启后限次；真实国产模型尚未验证。
- 新增 `requirements-agent.txt` 与 `requirements-agent-macos.lock.txt`；使用本机已安装包重建临时 wheel，在新 macOS ARM64 环境离线安装并通过依赖检查和 Agent 测试。这不是上游原始包或 Linux 安装验证，不包含 PostgreSQL saver。

- 本轮使用隔离任务和合成短文本请求配置的 DeepSeek 官方接口 `deepseek-flash`：TLS 握手失败，模型适配返回 `connection`，调用记录保存该失败，结果修订数量为 0、任务保留可重试状态；curl 对同一主机亦报告 SSL 握手失败。没有真实模型成功或工具调用验收。模拟接口与全新独立环境的 41 项 Agent 测试通过。

- 隔离 HTTP 接口 `http_api.py` 覆盖任务创建/读取、修订、确认、模型任务提交和状态查询；身份由服务端本地凭据建立，写入使用幂等键。`local_server.py` 仅绑定回环地址；独立进程经真实 HTTP 完成认证和任务创建。`local_model_worker.py` 每次执行一个模型任务，模型功能及凭据须由运行环境显式配置；没有连接企业身份或生产知识权限。
- 新建 macOS ARM64 隔离环境，使用本机已安装包重建的临时 wheel 离线安装 61 项固定依赖，`uv pip check` 与 45 项 Agent 测试通过。此后功能开关变更的相关 7 项测试另行通过；上游原始包、Linux、PostgreSQL 和生产部署仍未验证。

- 10-29 下午复测：早间 DeepSeek TLS 握手失败为瞬时本机网络故障，恢复后经隔离任务重测真实 `deepseek-flash` 通过：工具调用往返（合成库存查询，回答含正确数值）、JSON 输出模式、预算超限拒绝（类别 `limit`），共 3 次真实请求；工具回合 usage 输入 99/输出 11 tokens，`disable_thinking` 生效。仍为合成短文本，不构成成本或质量基线。注意：本机个人 SOCKS 代理环境变量会使 httpx 依赖 socksio，Agent 测试须置空代理运行（环境差异，非代码缺陷）。另修正 `tests.test_mcp_server` 过期版本断言（1.5.5→1.5.6，与当前服务声明一致）；置空代理后全仓 211 项测试通过。
